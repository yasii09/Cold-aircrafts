YASI GPT — FLIGHT OPS | Android Studio project
================================================

نسخه اصلاح‌شده پروژه بومی اندروید با Kotlin و Canvas دوبعدی است؛
این برنامه HTML یا WebView نیست و در حالت افقی اجرا می‌شود.

ساخت APK:
1) Android Studio را نصب کن.
2) پوشه YasiGPT_Android_Project را در Android Studio باز کن.
3) Gradle Sync را انجام بده و در صورت درخواست SDK Platform 35 را نصب کن.
4) از منوی Build گزینه Build Bundle(s) / APK(s) و سپس Build APK(s) را بزن.
5) فایل APK در مسیر app/build/outputs/apk/debug/ ساخته می‌شود.

اصلاحات این نسخه:
- رفع عبارت نامعتبر Kotlin در حرکت اهداف زمینی.
- اضافه شدن صفحه تنظیمات و کارکرد گزینه چهارم منو.
- اصلاح کنترل لمسی حرکت، شلیک، بمب و فلر.
- نگه داشتن دکمه‌های چپ/راست تا زمان برداشتن انگشت.
- اضافه شدن ذخیره انتخاب هواپیما در رابط آشیانه (انتخاب در طول اجرای فعلی).
- تثبیت تنظیمات افقی و تغییرات صفحه.

محدودیت:
این محیط Android SDK و Gradle اجرایی ندارد؛ بنابراین APK را اینجا کامپایل و روی گوشی آزمایش نکرده‌ام.
گرافیک فعلی با Canvas بومی رسم می‌شود و هنوز از spriteهای تصویری واقعی استفاده نمی‌کند.
